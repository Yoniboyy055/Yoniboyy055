## How I work

- **Systems over hype** — the system should work before the marketing says it works.
- **Evidence over assumption** — product states, customer outcomes, and production claims should be provable.
- **Real operations first** — software should reduce friction for the people actually doing the work.
- **Security and reliability by default** — auth, data boundaries, deployment safety, and failure states are part of the product.
- **Clarity over complexity** — fewer steps, cleaner decisions, and understandable workflows.
